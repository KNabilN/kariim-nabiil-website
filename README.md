# Kariim Nabiil Website

Personal website and course platform for Karim Nabil — Agentic AI Engineering, projects, and learning content.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (auth, LMS, CMS, leads)

## Development

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```
